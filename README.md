# C++ Beginner Programs

This repository contains 84 C++ practice programs written while learning
programming fundamentals in college.

## Topics

- Basics, input/output, and operators
- Conditional statements and switch-case
- Loops and pattern printing
- One-dimensional and two-dimensional arrays
- Functions
- Number, mathematics, and matrix programs

## Repository structure

Each source file has a descriptive name and is grouped by topic:

- `01_basics`
- `02_operators_conditions`
- `03_loops_patterns`
- `04_arrays_matrices`
- `05_functions`
- `06_math_and_number_programs`

## Compile and run

Using `g++`:

```bash
g++ path/to/program.cpp -o program
./program
```

On Windows PowerShell:

```powershell
g++ .\path\to\program.cpp -o program.exe
.\program.exe
```

These programs are for learning and practice purposes.
